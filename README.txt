Free GitHub Pages setup:
1. Create or use a free GitHub account.
2. Create a public repository named YOUR-USERNAME.github.io.
3. Upload index.html, the assets folder, and .nojekyll to the repository root.
4. Under Settings > Pages choose Deploy from a branch, main, /(root), then Save.
5. Use the URL provided by GitHub Pages. No custom domain purchase is needed.
